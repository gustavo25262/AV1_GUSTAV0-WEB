Lista de Tarefas - Clube do Remo
Descrição

Projeto desenvolvido para a AV1 da disciplina de Desenvolvimento Web.

A aplicação permite gerenciar tarefas de forma simples, utilizando JavaScript puro e consumo de API.

   Funcionalidades:
1.Adicionar tarefas
2.Excluir tarefas
3.Marcar tarefas como concluídas
4.Carregar tarefas da API JSONPlaceholder
5.Navegação para página de detalhes
6.Leitura de parâmetros da URL com URLSearchParams
7.Requisição assíncrona utilizando Fetch API
8.Tratamento de erros
9.Feedback visual de carregamento
10.Tecnologias Utilizadas
11.HTML5
12.CSS3
13.Bootstrap 5
14.JavaScript ES6+
15.Fetch API
16.Async/Await
17.JSON
18.Git
19.itHub
20.API Utilizada:

https://jsonplaceholder.typicode.com/todos
